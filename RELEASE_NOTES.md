## Jugar en Windows

1. Descargar **Raycasting-Game-0.5.1-Windows-x64-Portable.exe** en Assets.
2. Abrir el archivo con doble clic. No necesita instalación, Node.js ni un servidor externo.
3. Pulsar **ENTER DUNGEON**. Espacio permite saltar la introducción.

**Controles:** WASD para moverse, Shift para correr, mouse para mirar, clic o Espacio para disparar y Escape para pausar.

Para Windows de 64 bits. El primer inicio puede tardar unos segundos mientras el portable extrae sus archivos temporales.

El ejecutable no tiene firma digital; Windows puede mostrar un aviso de editor desconocido.

Compilado en GitHub Actions. Antes de publicar se comprueban el arranque del portable, el menú, el video de introducción, la carga de una partida, los recursos gráficos y de audio y el avance del bucle del juego. Esto no constituye una prueba completa de todos los niveles o equipos.
